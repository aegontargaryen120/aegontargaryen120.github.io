# Aegon Targaryen — GitHub Pages

A static personal website styled as the companion site to:

https://aegontargaryen120.substack.com/

## Deploy

1. Put these files in the root of the GitHub Pages repository.
2. Keep `index.html` at the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select the branch/folder containing these files.
5. Save and wait for GitHub Pages to build.

## Replace placeholders

- Replace the `HHG` feature artwork in `index.html` with the final publication/series artwork when available.
- Update the Part II/III links in `series/house-that-held-a-god.html` with the exact SubStack article URLs.
- Add real project URLs in `projects.html`.
- Add additional articles to `writing.html` as the publication grows.

## Structure

- `index.html` — homepage
- `writing.html` — writing archive
- `projects.html` — programming/projects
- `worldbuilding.html` — worldbuilding
- `about.html` — author/about page
- `series/house-that-held-a-god.html` — series index
- `css/style.css` — complete visual system
- `js/main.js` — mobile navigation and dynamic year
- `assets/images/` — place for logos, artwork, and article imagery
